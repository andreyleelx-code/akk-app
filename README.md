# AKK Digital 2.0

Мобильное веб-приложение Ассоциации казахстанских корейцев. Без сборки и зависимостей JavaScript.

## Структура

- Главная: направления, новости, ближайшие плановые события.
- Сообщество: МДК, Корейский театр, «Корё ильбо», Деловой клуб, филиалы, структура.
- Афиша: фильтры, карточки событий, избранное, выгрузка в календарь ICS, переход на Ticketon.
- K-PARK: концепция, история, участие, официальные источники.
- Профиль: анкета, черновик, избранное, установка PWA, тема оформления.
- `previous/`: полная исходная версия, включая прежние сценарии кабинета и администрирования.

## Запуск и редактирование

Изменения оформления: `style.css`; поведения: `app.js`; публикаций: `news.json`.
Настройки существующего сервера: `config.json`. Только публичный publishable key; секретные ключи сюда не добавлять.

Локально: `python3 -m http.server 8080 --directory .`. Затем открыть http://localhost:8080.

## GitHub Pages

Архив GitHub Pages содержит файлы из `dist` в корне. Загрузите их в корень репозитория `app-akk` с сохранением подпапок. Settings → Pages → Deploy from a branch → main → / (root). Все пути относительные, переход `#kpark` поддерживается. Сначала сохраните резервную копию текущего репозитория.

В архив также включены `scripts/update-news.py` и `.github/workflows/news.yml`: расписание раз в 6 часов обновляет публичные заголовки редакции и даты, когда сайт-источник доступен. Включите GitHub Actions и разрешение Workflow permissions → Read and write permissions. При ошибке источника сохранённая лента не удаляется. Из-за ограничений источника сбор не гарантируется; ошибки видны в журнале Actions.

## Данные и честные состояния

- Избранное, регион и тема хранятся локально. Черновик анкеты — только после явного сохранения.
- Анкета отправляется в существующую функцию `submit_guest_questionnaire`. Успех показывается только после успешного ответа. Отправка не создаёт подтверждённое членство.
- Сервер Supabase при проверке из среды разработки вернул HTTP 503; реальная доставка анкет не подтверждена. Схема базы и политики не изменялись. Перед запуском для участников необходима проверка владельцем проекта.
- Вход по email использует существующий Supabase Auth. SMS-провайдер не добавлялся. Redirect URL нового домена должен быть разрешён в настройках проекта. Проверка доставки письма и OTP не выполнялась.
- Перед отправкой реальных данных ознакомьтесь с действующими правилами обработки персональных данных АКК. Встроенная страница описывает фактическое поведение приложения и не заменяет утверждённый документ организации.
- Интеграция с Google Sheets в исходном архиве отсутствует. Эта версия её не объявляет готовой; для настройки нужны параметры целевой таблицы и серверный доступ.
- Подтверждённый QR, часы волонтёров и сертификаты остаются в исходном кабинете. Новые фиктивные карты, часы и скидки не создаются.
- Оплата пожертвований не имитируется. Используются официальная страница проекта и контакты; реквизиты и Kaspi не выдуманы.
- Афиша 2027 содержит плановые события из задания с явной пометкой. Запись и цены не выдуманы. Ticketon открывается внешне; интеграция API продажи билетов не заявляется.
- Адреса филиалов импортированы из исходника и помечены как справочные; личные телефоны руководителей не публикуются.
- Фото церемонии K-PARK, театра и архивная обложка газеты сохранены локально. Недоступные изображения исходного кабинета заменяются нейтральной иллюстрацией; она не выдаётся за фотографию события.

## Проверки

`node --check dist/app.js`, `node --check dist/sw.js`.
В браузере: пять основных разделов, поиск, выбор региона, фильтры, избранное, черновик анкеты, настройка темы и адаптивные экраны.

Публикация Sites создаёт отдельную версию. Исходный GitHub Pages не изменён без доступа к его репозиторию.
