AKK DIGITAL — ЗАГРУЗКА В ОСНОВНОЕ ПРИЛОЖЕНИЕ

1. Распакуй ZIP на компьютере. Сам ZIP в GitHub загружать не нужно.
2. Для резервной копии открой репозиторий app-akk → Code → Download ZIP.
3. В репозитории https://github.com/andreyleelx-code/app-akk
   выбери ветку main → Add file → Upload files.
4. Перетащи ВСЁ СОДЕРЖИМОЕ распакованного архива, включая папки
   assets, icons и previous. Не загружай внешнюю папку целиком:
   index.html должен оказаться прямо в корне репозитория.
   Подтверди замену одноимённых файлов кнопкой Commit changes.
   Удалять старые файлы перед загрузкой не требуется.
5. Settings → Pages → Source: Deploy from a branch;
   Branch: main; Folder: / (root); Save.
6. Дождись зелёного статуса Pages в разделе Actions.
7. Открой https://andreyleelx-code.github.io/app-akk/#home
   На компьютере обнови Ctrl+Shift+R. Если установленное приложение
   показывает прежнюю версию, закрой его полностью и открой снова.
   Если это не помогло, очисти данные сайта в браузере — локальные
   черновики и избранное при этом будут удалены, сначала скопируй их.

ПРОВЕРКА ПОСЛЕ ЗАГРУЗКИ
• Главная: «Своё сообщество. Рядом.»
• Сообщество → Возможности: подбор интересов, поиск и фильтры.
• Профиль: кнопка «Назад» сохраняет введённую анкету на устройстве.
• K-PARK: площадь 10 га, фото церемонии закладки.
• Корё ильбо: архивная обложка и справка о газете.

ЧТО ВХОДИТ
Это новое оформление приложения, которое работает на GitHub Pages
по прежнему адресу, а не ссылка на отдельный сайт ChatGPT.
Исходный кабинет и администрирование сохранены в папке previous.
Из нового профиля есть переход в прежний личный кабинет.

ОГРАНИЧЕНИЯ
Смена интерфейса не исправляет недоступный сервер Supabase.
Отправка анкет зависит от существующего сервера и требует проверки
владельцем. SMS и перенос в Google Sheets не настроены.
Отклики в разделе возможностей — локальные черновики, не отправленные
заявки. Информация о направлениях не означает открытый набор.

АВТООБНОВЛЕНИЕ НОВОСТЕЙ (НЕОБЯЗАТЕЛЬНО)
Файлы .github/workflows/news.yml и scripts/update-news.py приложены.
Если папка .github не загрузилась через браузер, создай workflow:
Actions → New workflow → set up a workflow yourself, скопируй текст
из .github/workflows/news.yml и сохрани. В Settings → Actions → General
разреши Read and write permissions для workflow.
Обновляются заголовки, ссылки и даты; доступность источника не гарантируется.

Никакие пароли, токены или секретные серверные ключи добавлять не нужно.
